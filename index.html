Prototype FLUXO — mode démo local par défaut, ou synchronisé avec votre base Supabase une fois configuré (icône ⚙).

Connexion des données

Collez les coordonnées de votre projet Supabase (Dashboard → Settings → API Keys, clé « publishable »). Sans configuration, FLUXO tourne en mode démo local, sans serveur.

Ces valeurs peuvent aussi être définies pour tous les postes dans un fichier config.js déposé à côté de fluxo.html. La clé publique (« publishable », ex-anon) est conçue pour être exposée : la sécurité vient des règles d'accès de la base (RLS), pas du secret de la clé.
